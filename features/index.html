汽車美容職人專屬管理系統

從顧客預約到門市營運，使用同一套資料

Hando 神美把預約、車主與車輛紀錄、開單結帳、庫存、員工與管理報表串成門市可執行的流程。

核心功能

LINE／Google／IG 預約

讓車主由常用管道進入預約，門市集中查看時段、車輛與服務項目。

車主 × 車輛雙 CRM

分別管理車主聯絡與偏好、車輛基本資料、施作、消費與保養紀錄。

POS 與消費紀錄

支援開單、結帳、服務與商品設定，並保留交易的付款與消費明細。

進銷存與耗材

集中查看商品、耗材與庫存資訊，作為採購、盤點與門市補貨的依據。

排班、出勤與薪資

管理員工班表、打卡、業績與薪資計算所需資料，減少重複彙整。

多門市與組織權限

從 Web 後台查看門市、財務與營運資訊，並依使用者角色設定權限。

三種門市操作介面

介面主要使用者適合工作
手機行動管家美容師、門市人員班表、會員查詢、作品集、薪資與耗材
平板店務助手櫃台、現場人員預約場務、開單結帳、會員與車輛資料
Web 後台店長、營運與管理者財務、報表、多店、組織權限與服務商品
導入前建議確認：現有預約管道、車籍與會員資料格式、門市數、員工權限、付款流程與必要報表。這些資訊會影響設定方式與導入時間。
